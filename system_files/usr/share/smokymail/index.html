Smoky Mail

Ajoute une boîte mail. Tu pourras en ajouter d'autres ensuite : tout arrive dans une seule liste, triée par Claude.

Microsoft n'accepte plus les mots de passe dans les applis de messagerie : Outlook se connecte avec la page de connexion officielle de Microsoft. Smoky Mail ne voit jamais ton mot de passe.

Une seule fois : crée l'identifiant d'application (gratuit, 5 minutes) sur portal.azure.com avec ton compte Microsoft :

  1. Recherche « Inscriptions d'applications » → Nouvelle inscription.
  2. Nom : Smoky Mail ; types de comptes : comptes dans un annuaire organisationnel et comptes Microsoft personnels ; laisse l'URI de redirection vide → S'inscrire.
  3. Menu Authentification → « Autoriser les flux de clients publics » : Oui → Enregistrer.
  4. Copie l'ID d'application (client) et colle-le ici.

Tri automatique par Claude

Claude lit l'expéditeur, l'objet et le début de chaque nouveau mail, puis le range (Important, Cours, Achats…) avec un résumé d'une ligne. Il utilise ton compte Claude, le même que l'appli : pas de clé d'API, rien à payer en plus ; le tri compte simplement dans ton forfait (Pro ou Max). Claude n'a accès à rien d'autre : ni tes fichiers, ni Internet.
